01

New visitor lands on page

Sees hero with value prop and dashboard preview. Scrolls down or clicks nav.

Hero → Trust bar (social proof) → Scrolls to product
02

Exploring the product

Visitor clicks "Product" in nav or "See how it works" in hero. Both go to #product.

Nav → Product → #product intro → Website & Booking → Schedule & Queue → CRM & Follow-ups
03

Building trust

Visitor checks how it works, security, and testimonials before committing.

How it works → Security (2x2 grid) → Testimonials
04

Ready to convert

Visitor clicks "Request a demo" (nav or pricing section) or "Start your workspace" (hero). All go to /login.

Pricing card → Request a demo → /login
05

Existing user returns

Clicks "Sign in" in nav directly. Skips the whole page.

Nav → Sign in → /login → /dashboard
06

Has questions

Scrolls to FAQ section. Clicks any of the 8 expandable questions.

FAQ accordion → Reads answer → Final CTA → Request a demo → /login
07

All CTAs lead to /login

Every conversion button on the page goes to the same destination.

Hero: Start workspace → /login
Nav: Request a demo → #pricing
Pricing: Request a demo → /login
Final CTA: Request a demo → /login
