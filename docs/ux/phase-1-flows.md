# sPhase 1 UX flows

## Public entry

Landing page → explanation of the product → workspace entry point. The page is responsive, keyboard navigable, uses semantic headings, and does not imply that public booking is available yet.

## Dashboard entry

Workspace entry → clinic context chip → overview metrics → today’s schedule. The shell includes tablet-friendly spacing and a clear empty future for loading/error states when live data is introduced.

## Deliberate boundary

The workspace is a visual shell only in Phase 1. Authentication and clinic data are not simulated, so there is no misleading sign-in or fake patient data.
